# Reflection

In this laboratory, I learned how to work with a cloud-based Ubuntu Linux environment and use basic Linux commands.

I learned how to create and manage users, navigate directories, create files and folders, and gather basic system information.

I also learned how to organize my laboratory files using Markdown and prepare a Cloud Computing Portfolio for GitHub.

This activity improved my confidence in using the Linux terminal and helped me understand the importance of proper file organization and documentation in cloud computing.
