# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduces the basic concepts and tools used in a cloud-based Linux environment.

## Objectives

- Access a cloud-based Linux environment.
- Explore and navigate Linux.
- Gather basic system information.
- Organize files and directories.
- Create and maintain a GitHub repository.

## Activities Performed

- Accessed the KillerCoda Ubuntu environment.
- Created and configured a Linux user.
- Gathered basic system information.
- Created and organized the laboratory files.
- Prepared the Cloud Computing Portfolio.

## Linux Commands Used

- `whoami`
- `pwd`
- `hostname`
- `ls`
- `mkdir`
- `touch`
- `cat`
- `nano`
- `uname`
- `lscpu`
- `free`
- `df`
- `git`

## Skills Learned

I learned how to navigate a Linux environment, gather system information, organize files and directories, document technical work using Markdown, and prepare a GitHub portfolio.
