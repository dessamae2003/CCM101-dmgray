# Laboratory Activity 6: Mission 6 - The Cloud Deployment Engineer

## Mission Overview
Transitioned from deploying single standalone containers to implementing Infrastructure as Code (IaC) using Docker Compose. Successfully deployed a two-tier enterprise private cloud storage solution combining Nextcloud and MariaDB.

## Objectives
* Explain multi-tier application architectures and container tier separation.
* Write a properly formatted YAML configuration file (`docker-compose.yml`).
* Use Linux command-line text editors (`nano`).
* Deploy, verify, and gracefully tear down a multi-container application stack.
* Document IaC principles and reflect on cloud deployment workflows using Markdown.

## Commands Executed
* `mkdir nextcloud-deployment`
* `cd nextcloud-deployment`
* `nano docker-compose.yml`
* `docker-compose up -d`
* `docker-compose ps`
* `docker-compose down`

## Skills Learned
* Multi-container orchestration with Docker Compose.
* Internal container service discovery and networking.
* Environment variable security practices.
* Infrastructure as Code documentation using Markdown.
