## Host Server Metrics
* **Total RAM Available:** 1.9Gi

---

## Importance of Disk Space Check
Checking available disk space before a massive traffic surge is critical because web servers generate heavy access and error logs; running out of storage space will cause database writes to fail, corrupt application state, and crash the production environment.
