# Laboratory 02 - Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?
The compute resource is arguably the most important cloud infrastructure component because it acts as the processing engine that executes application logic, handles user requests, and drives dynamic services. Without compute power, stored data remains static and networks have no active traffic to route or process.

## 2. How does Linux support cloud computing?
Linux provides the foundational operating system layer that powers the vast majority of cloud infrastructure virtual machines, containers, and hypervisors. Its stability, lightweight design, and granular command-line manageability allow cloud providers to efficiently allocate hardware resources and scale services securely.

## 3. Why is technical documentation important before deploying infrastructure?
Technical documentation acts as a vital blueprint that aligns technical teams, clarifies architecture dependencies, and prevents costly configuration errors during deployment. It ensures full transparency, establishes standard operating procedures, and provides a clear historical record for future troubleshooting and scaling.

I also gained practical experience comparing major public cloud service ecosystems and visualizing network architectures using Canva.
