| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Google Cloud Storage |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of services because it entered the cloud market first and has spent years expanding its ecosystem. It features the largest variety of specialized tools, ranging from foundational compute and storage to advanced machine learning and IoT technologies.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is the recommended platform for organizations using Microsoft products because it offers native, seamless integration with Windows Server, Active Directory, and Office 365. This compatibility simplifies hybrid cloud management, enterprise security compliance, and license migrations.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for these areas because Google originally created Kubernetes and provides industry-leading data analytics tools. Its robust machine learning pipelines and custom tensor processing units (TPUs) make it a powerhouse for AI-driven projects.

### 4. What similarities did you observe among the three cloud providers?
All three major cloud providers rely on the same fundamental infrastructure pillars: compute instances, object/block storage, virtual networks, and secure identity management. They also share global data center distribution models, scalable pay-as-you-go pricing frameworks, and comprehensive management dashboards.
